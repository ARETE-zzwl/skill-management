# Security Policy

## Supported Versions

This project is an early demo. Security fixes are handled on the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for sensitive reports.

Send a private report through GitHub's private vulnerability reporting if it is enabled for this repository, or contact the repository owner directly through GitHub. Include:

- affected command, endpoint, or workflow
- reproduction steps
- expected impact
- any suggested mitigation

## Local Data

The project can install skills into `.agents/`, `.claude/`, and `.skillmgr/`. These directories are local generated data and should not be committed unless a future change explicitly documents otherwise.
