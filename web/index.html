GET STARTED

5 分钟上手流程

先从精选库下载一个 skill，再查看说明和安全扫描，最后共享安装到 Codex 与 Claude Code。安装完成后，在对话里直接点名调用。

  1. 选择 Skill 在 精选库 搜索 `nature`、`react`、`microsoft` 等关键词。
  2. 下载导入 点击“下载导入”，或粘贴 GitHub tree URL 到快捷导入框。
  3. 查看说明 在 已导入 点击“说明”，检查调用示例、兼容矩阵和安全扫描。
  4. 共享安装 点击“共享”，把 skill 同步到所有支持的 agent；也可以只装到 Codex 或 Claude。
  5. 显式调用 例如：使用 nature-writing skill，帮我润色这段摘要。
